# V1 calendar and project history

- Status: Accepted
- Scope: Wayfinder ticket 5, `Define calendar and project-history retrieval behavior`

Kept's V1 retrieval experience uses a monthly calendar grid and project history, with lightweight navigation so the journal remains the primary product.

## Calendar

- Show a monthly grid with a simple marker on any date that has raw notes or saved entries.
- Select today by default.
- Let users open today and past dates, including empty dates. Future dates stay visible but disabled.
- Open a selected date in a large journal card over the calendar, keeping the calendar visible behind it.
- Provide previous-month and next-month controls, plus a `Today` button.

## Project history

- Clicking a project name opens that project's history in the same large-card style.
- Show saved entries only, grouped by journal date with the newest date first.
- Show an `Uncategorized` history alongside named projects.
- Keep archived projects and their history available in the archived section.
- V1 has no search or advanced filters. Calendar navigation and project selection are enough.

## Consequences

The calendar does not expose separate note, review, or processing states in its grid marker. Users see those details after opening the journal card. Future-date journaling and broad cross-project search remain out of scope for V1.
