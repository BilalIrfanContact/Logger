# Name history

Kept was previously named **Logger** during the V1 planning and foundation work.

Kept is now the canonical product and codebase name. The previous name is retained here as a deliberate historical alias so old GitHub discussions, links, and references can be recognized without carrying stale branding through the application.

The GitHub repository slug may continue to contain the previous name until it is renamed separately in GitHub. Existing links to issues and decisions should remain valid during that transition.
